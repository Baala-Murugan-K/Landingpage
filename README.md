# Landingpage
The "Study MBBS Abroad" landing page is designed to provide prospective students with essential information about studying MBBS in various countries. The page features sections that highlight the benefits of studying abroad, lists top countries for MBBS programs, outlines the admission process, and includes a lead generation form for capturing user inquiries. The landing page is fully responsive, ensuring a seamless experience across devices.
# Technologies Used
This project utilizes the following technologies:

- **HTML**: For the structure and content of the landing page.
- **CSS**: Styled using Bootstrap for responsive design and layout.
- **JavaScript**: For form validation and interactivity.
- **Bootstrap**: A popular CSS framework that helps in creating responsive and mobile-first websites.
